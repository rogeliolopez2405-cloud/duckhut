# Make Duckhut better

Have a fun idea? Open a feature request in the repository's Issues tab. Explain what a player would do and why it would be fun. Small ideas are welcome.

For bugs, include your browser, device, steps to reproduce, and what you expected. A screenshot or short recording helps.

For code contributions:

1. Fork the repository and create a branch.
2. Open `index.html` or serve the folder locally.
3. Make a focused change and check mouse, touch, and keyboard controls where relevant.
4. Check starting, three-shot limits, misses, round progression, pause/resume, and restarting.
5. Open a pull request describing the change and how you checked it.

Use original or appropriately licensed artwork and sounds. Keep the prototype easy to run without a build system. Be kind and constructive when discussing other people's ideas.
